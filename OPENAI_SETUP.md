# Astra → статья → DeepSeek → GPT-4.1 mini → Telegram

## Подключение

GitHub Actions Secrets: `OPENAI_API_KEY`, `DEEPSEEK_API_KEY`, `TELEGRAM_BOT_TOKEN`,
`TELEGRAM_CHANNEL_ID`. Ключ OpenAI требует доступа к `gpt-6-astra` и
`gpt-4.1-mini-2025-04-14`. GNews-ключи больше не используются. Workflow явно
задают `SOURCE_VERIFIER=openai`; отката проверки на DeepSeek нет.

## Сбор

Основной сборщик работает каждый час. Если в очереди меньше двух проверенных
постов, Astra ищет до пяти ссылок. Бот принимает только источники и цитаты
поискового инструмента, самостоятельно загружает HTML статей и проверяет дату.
Статьи старше 48 часов, без подтверждаемой даты, недоступные страницы и переходы
за пределы разрешённых доменов пропускаются. Текст ответа Astra не является
доказательством фактов. Из статьи извлекается до 12 000 символов с завершением
на границе предложения; поддержка зависит от разметки сайта.

DeepSeek отбирает материал и пишет пост. До сверки удаляются повторы и служебные
фразы, нормализуется Telegram HTML. GPT-4.1 mini проверяет пост по сохранённому
исходнику. Только проверенные черновики переходят к публикации.

Каждый запуск готовит максимум один пост. Остальные ссылки доступны следующим
запускам без повторного поиска. Кеш, включая пустой результат, действует до конца
дня Дубая. Даты статей проверяются заново при чтении из кеша.
RSS/GNews не вызываются. Дополнительный Priority Media Collector оставлен только
для ручного запуска той же схемы; его расписание отключено.
Публикация выполняется на 5-й минуте каждого часа.

## Бюджет

Общий предел — **$3 в месяц UTC** для запросов этого бота, без DeepSeek,
налогов и других приложений с тем же ключом.

| Операция | Ограничение |
|---|---|
| Поиск | gpt-6-astra, reasoning low, Standard tier |
| Один запрос | Один web_search, low context, default return budget |
| Выход поиска | До 2 000 токенов, включая рассуждения |
| Вход запроса | JSON UTF-8 + 1 024 байта запаса ≤ 8 000 |
| Поиски в сутки UTC | По умолчанию 1; допустимо 0–2 |
| Проверки в сутки UTC | До 8 |
| Резерв проверки | $0,01056; не возвращается |
| Резерв Astra | **$2 до запроса**, затем пересчёт по подтверждённому usage |
| Повторы HTTP | Отключены |

Тарифы Astra на 19.09.2026: $10/M input, $50/M output, $12,50/M cache writes;
вызов поиска — $0,01 плюс токены результатов. Все входные токены учитываются
по более высокой ставке cache writes, без скидки кеша. Резерв $2 покрывает 128K
поискового контекста, ограниченный запрос с повторным входом после инструмента,
выход и инструмент с запасом. Числовое значение return_token_budget API не
поддерживает; используется default. Тарифы проверки: $0,40/M input и $1,60/M output.

Пересчёт Astra допускается только по завершённому ответу ожидаемой модели,
одному завершённому поиску, Standard tier и корректному usage. Пересчёт однократный.
Таймаут, отказ API, неполный ответ, неизвестная модель или потерянный usage
оставляют **весь резерв $2 занятым**. Старые расходы и резервы не изменяются.

Перед новым поиском должны оставаться **$2 + $0,01056 на проверку**.
Поэтому поиск может остановиться, когда учтено около $1, даже если фактический
расход меньше $3. Это сознательный запас: **ежедневные поиски и публикации за $3
не гарантируются**. Кеш и готовые посты доступны после остановки поиска.
Итоговый счёт: [OpenAI Usage](https://platform.openai.com/usage).

GitHub Actions Variables:

- OPENAI_MONTHLY_BUDGET_USD: 0–3, по умолчанию 3.
- OPENAI_MAX_CALLS_PER_DAY: 0–8, по умолчанию 8.
- OPENAI_MAX_SEARCHES_PER_DAY: 0–2, по умолчанию 1.
- OPENAI_NEWS_SEARCH_ENABLED=false останавливает получение новых статей.

## Сохранность расходов

Не удалять и не обнулять storage/dubai_news/openai_budget.json.
Журнал v1 принимает прежние записи и новые astra_requests без сброса истории.
При повреждённом, отсутствующем или заблокированном журнале запросы запрещены.
Все workflow используют общую concurrency-группу и актуальную main.

Перед каждым платным запросом резерв атомарно записывается и отдельно отправляется
commit/push в main. Ошибка push отменяет запрос. Пересчитанный расход и кеш
сохраняет финальный шаг. Следующий резерв также отправляет актуальный журнал
до нового запроса. Сбой сохранения может завысить резерв, но не обнулить его.
Не запускать независимые копии с одним ключом: их журналы не суммируются.

## Ручная проверка

1. Actions → Dubai News Collector → Run workflow, ветка main.
2. При необходимости отметить обход дневного лимита. Он не обходит месячные $3,
   резерв перед запросом, кеш или проверку фактов.
3. Проверить new_draft, discovery_status, openai_search_calls,
   openai_search_cache_hits, reason и technical_errors в результате.
4. При new_draft=true запустить Publish News to Telegram или дождаться расписания.

Зелёный запуск с NO POST означает отсутствие нового поста; причина указана
в результате. Ошибка API делает запуск неуспешным. Два готовых поста в очереди
останавливают сбор до их публикации.

Локальные тесты: python -m pytest tests -q. API в тестах подменяются;
доступ к Astra и качество источников проверяются реальным запуском.
