# Экономный поиск → статья → DeepSeek → проверка → Telegram

## Настройка

Поиск и отдельная проверка фактов используют `gpt-4.1-mini-2025-04-14`.
DeepSeek отбирает материалы и пишет посты. Secrets: OPENAI_API_KEY,
DEEPSEEK_API_KEY, TELEGRAM_BOT_TOKEN, TELEGRAM_CHANNEL_ID. Рабочие workflow
требуют SOURCE_VERIFIER=openai; ошибки проверки не вызывают отката на DeepSeek.

Коллектор запускается по расписанию, вручную и после изменения
src/openai_news_search.py в main. Последний случай проверяет развёрнутый поиск
через обычный сбор с теми же бюджетными ограничениями. Публикация отдельная.

## Поиск и качество

Один основной поиск и максимум один дополнительный, если первая партия не дала
доступных свежих статей. Второй запрос получает URL и причины отсева. На каждый
запрос разрешён один web_search, low context, до 1 000 выходных токенов.
Параметры reasoning, return_token_budget и серверные filters не используются:
этот pinned mini ранее отклонял filters. Домены заданы в промпте и проверяются кодом.

Из реальных цитат и источников инструмента берётся до пяти ссылок, максимум две
от одного издателя. Gulf Business исключён из поиска из-за HTTP 403 в Actions.
Архивы, рубрики с известными URL-маркерами, теги и PDF отфильтровываются.
Остальные страницы проходят проверку HTML, даты и наличия текста. Статьи старше
48 часов, неподтверждённые даты и неоднозначные данные отклоняются.

Бот сам загружает текст статьи (до 12 000 символов с границей предложения).
Текст модели поиска не используется как исходник. DeepSeek пишет пост,
применяются очистка повторов и оформление Telegram, затем отдельный запрос
GPT-4.1 mini проверяет соответствие сохранённому исходнику.

Обе поисковые партии и ошибки API кешируются до конца дня Дубая. У дополнительной
партии постоянный ключ: почасовые запуски не покупают новые попытки из-за изменений
причин отсева. После API-ошибки второго запроса нет. Если все доступные статьи отклонены редактором, оставшаяся попытка поиска
получает причины отказа. При ошибке API или остановке проверки поиск прекращается. Старый кеш Astra отделён от нового кеша mini.

## Расходы: предел $3 в месяц UTC

| Операция | Консервативный резерв |
|---|---|
| Один поиск GPT-4.1 mini | $0,025 |
| Одна проверка поста | $0,01056 |
| Поиск с запасом на проверку | Нужно минимум $0,03556 свободного бюджета |

Тарифы mini: $0,40/M входных и $1,60/M выходных токенов. Поисковый инструмент
стоит $0,01 за вызов; для mini поисковые материалы тарифицируются фиксированным
блоком 8 000 входных токенов. Резерв учитывает ограниченный промпт и выход с запасом.
Резервы mini не возвращаются даже при ошибках; usage учитывается отдельно.
Итоговый счёт проверяется в [OpenAI Usage](https://platform.openai.com/usage).

Все прежние расходы Astra и проверки остаются в журнале. Его нельзя удалять
или обнулять. Журнал v1 продолжает читать astra_requests; новые поиски увеличивают
search_calls. Перед каждым запросом резерв атомарно сохраняется и отправляется
в main отдельным commit/push. При ошибке push платный вызов отменяется.
Общая concurrency-группа не допускает одновременной записи workflow.

Variables:

- OPENAI_MONTHLY_BUDGET_USD: 0–3, по умолчанию 3.
- OPENAI_MAX_SEARCHES_PER_DAY: 0–2, по умолчанию 2.
- OPENAI_MAX_CALLS_PER_DAY: 0–8 проверок, по умолчанию 8.
- OPENAI_NEWS_SEARCH_ENABLED=false останавливает получение новых статей.

Два поиска и две проверки в день за 31 день резервируют около $2,21.
Это пример расхода, а не гарантия количества публикаций. Месячный общий предел
сохраняется и при ручном обходе дневного лимита. DeepSeek, налоги и другие
приложения с тем же ключом в этот предел не входят.

## Проверка

Actions → Dubai News Collector → Run workflow → main. Отчёт показывает
new_draft, discovery_status, replacement_search, discovered_urls, openai_search_calls,
reason. При new_draft=true запустить Publish News to Telegram или дождаться расписания.

Bot tests проверяет код на Python 3.10 без платных API. Check article access
проверяет загрузку кешированных ссылок без моделей и публикации. Причины отсева:
http_403, outside_48h_window, missing_publication_date, not_an_article и другие.
