## Реализация и ограничения

config/retro_commons_reviews.json — явный реестр единственной вручную проверенной
карточки: автор, дата, описание с неопределённостью, источник Flickr, лицензия,
размеры и SHA-1. Бесплатный API loader перед будущей верификацией повторно
проверяет эти поля и оригинальный image URL; изменение любого существенного
поля закрывает отбор. DateTime загрузки не используется как дата съёмки.
Идентичность оригинала привязана к SHA-1, а не tracking/query URL.

Commons допустим только в явном staging выборе: production run сохраняет политику
The National. Discovery известной карточки получает manual_usage_review_required,
не approved. Другие Commons-карточки и домены остаются запрещёнными.
usage_review дополнительно требует точные автора, атрибуцию, лицензию, SHA-1,
неизменённое фото, ShareAlike и отдельно проверенный numeric test channel ID.
Сам факт лицензии не разрешает production или тестовую отправку без команды пользователя.

config/retro_beach_draft.json — pending_approval, telegram_republication=false,
channel_id=null. Фактчекинг verify_summary не отключён и не имитирован как успешный:
реальный платный вызов не запускался, source_verification=not_run. Черновик нельзя
передать в sendPhoto до согласования, тестового destination и штатной верификации.
Тесты доказательств/прав — offline fixtures, не проверка готовности реального Telegram.

Оригинал сохранён в Library: libfile_e31c5cbe372c8191ba69154c8a49d650,
file_0000000041a0820e9d46d825c0738b36, размер 46 184 байта. Ответ создания succeeded
сохранён локально рядом с checkout. Windows не поддерживает os.setxattr этого
Library helper: локальные xattrs не записаны, но создание файла Library подтверждено;
идентичность сохранена в library-result.json. Локальный Windows путь не является
вложением родительского чата.
