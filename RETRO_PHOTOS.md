# Старый Дубай

## Недельная рубрика — подготовленный перенос

Существующее расписание: суббота 14:00 Дубая (10:00 UTC), без изменений.
Локальная ветка предлагает отправку самого фото из явной вручную одобренной
очереди `config/retro_publish_queue.json`. Main пока не обновлён и публикует старым
кодом. Полная схема, поля ручного review, проверки и ограничения:
[RETRO_MAIN_PREPARATION.md](RETRO_MAIN_PREPARATION.md).

Очередь сейчас пуста. Новый путь сообщает `no_reviewed_photo / manual_queue_required`
без платных запросов и отправки. Discovery из Serper не является разрешением
на публикацию. Для каждого выпуска нужны визуальный выбор оригинала, доказательства
автора/даты/места/происхождения, право на перепубликацию, атрибуция и согласованный
полный caption. Commons допускается только по конкретной проверенной карточке,
а The National требует документированного разрешения; ссылка не заменяет лицензию.

После ручного approval недельный запуск повторно проверяет доказательства,
выполняет штатный фактчек полного caption в прежнем общем бюджете и только при
approved отправляет sendPhoto. Автоматические writer/emoji стадии и платный поиск
в недельной цепочке не используются. Автономная редакционная работа не обещается.
История production, Creek replacement и тестового сообщения 76 защищает от повторов.
Маркеры verifying/sending предшествуют side effects; неизвестный исход требует
сверки, а не повторной отправки. Исторический первый пост не является fallback.

## Отдельный поиск и галерея

Secret `SERPER_API_KEY` используется только в Actions → **Find retro Dubai photos**
→ Run workflow → main. Один запрос Serper на календарную неделю UTC (понедельник–воскресенье),
без автоматических повторов; повторный запуск использует сохранённую подборку.
Темы меняются по неделям: Dubai Creek, Deira, Sheikh Zayed Road, архивный Дубай.
Модели OpenAI для подбора не вызываются. Оплата Serper отдельная.

После запуска скачайте artifact **retro-photo-gallery**, распакуйте и откройте
`retro-photos.html`: изображения загружаются по ссылкам из интернета. Есть ссылки
на страницы источников. Недоступные изображения могут не отображаться.
Метаданные хранятся в `storage/dubai_news/retro_photos.json` отдельно от новостей.
Повторы определяются по адресу изображения без параметров; копии на других
сайтах могут оставаться. Год, место и лицензия не выводятся из поискового запроса:
их нужно подтвердить по источнику. Автопубликация этой подборки не включена.

Перед платным запросом недельный резерв отправляется в main. Ошибка API или
таймаут сохраняет использованную попытку до следующей недели; проверьте ключ
и баланс Serper. Журнал поиска не нужно удалять для повторного запуска.
