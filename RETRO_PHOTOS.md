# Ретрофото Дубая

## Автоматическая рубрика

**Publish Dubai Then** публикует один пост по субботам в 14:00 Дубая (10:00 UTC).
Запуск вручную использует тот же недельный лимит. Первое изменение
`config/retro_first_post.json` в main запускает согласованный первый пост.
Повторная отправка того же снимка блокируется журналом
`storage/dubai_news/retro_publications.json`.

Формат: текст с HTML-заголовком, абзацами, цитатой при наличии в исходнике,
ссылкой на оригинал и крупным превью страницы. Наличие превью определяет Telegram;
бот не загружает фотографию отдельным вложением. Первый снимок имеет пометку
ONE TIME USE ONLY у издателя, поэтому используется ссылка на оригинал.

Следующие посты: Serper ищет на The National (один запрос в неделю), бот находит
подпись именно к найденному изображению, проверяет наличие места и года/десятилетия.
DeepSeek пишет короткий текст только по этой подписи; GPT-4.1 mini сверяет все факты.
Бюджет OpenAI общий с новостями, максимум $3/месяц. Для первого согласованного
поста используется также текст статьи. Репосты соцсетей автоматически не публикуются.
Если нет подходящего фото, выпуск пропускается с объяснением в Actions.

Подготовка и отправка резервируются до вызовов: максимум одна подготовка/проверка
за неделю. Ошибка, отказ проверки или неизвестный результат доставки не вызывают
повторных платных запросов или повторной отправки. При send_unknown нужно сверить
канал и журнал вручную. Нельзя удалять журнал для обхода защиты от дублей.

## Отдельный поиск и галерея

Secret `SERPER_API_KEY` используется только в Actions → **Find retro Dubai photos**
→ Run workflow → main. Один запрос Serper на календарную неделю UTC (понедельник–воскресенье),
без автоматических повторов; повторный запуск использует сохранённую подборку.
Темы меняются по неделям: Dubai Creek, Deira, Sheikh Zayed Road, архивный Дубай.
OpenAI и DeepSeek для подбора не вызываются. Оплата Serper отдельная.

После запуска скачайте artifact **retro-photo-gallery**, распакуйте и откройте
`retro-photos.html`: изображения загружаются по ссылкам из интернета. Есть ссылки
на страницы источников. Недоступные изображения могут не отображаться.
Метаданные хранятся в `storage/dubai_news/retro_photos.json` отдельно от новостей.
Повторы определяются по адресу изображения без параметров; копии на других
сайтах могут оставаться. Год, место и лицензия не выводятся из поискового запроса:
их нужно подтвердить по источнику. Автопубликация этой подборки не включена.

Перед платным запросом недельный резерв отправляется в main. Ошибка API или
таймаут сохраняет использованную попытку до следующей недели; проверьте ключ
и баланс Serper. Журнал поиска не нужно удалять для повторного запуска.
