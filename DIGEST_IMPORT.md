# Подборка из сводки ChatGPT

В develop включён режим digest в config/news_discovery.json.
В него импортированы четыре ссылки из сводки пользователя за 29 сентября 2026 года.
Текст сводки не используется как подтверждённый источник: бот загружает сами статьи,
сверяет дату публикации (48 часов), проверяет повторы и использует только текст издателя.

Этот режим не вызывает платный поиск OpenAI, даже при включённом Refresh search.
Пустая, устаревшая или некорректная подборка не включает запасной платный поиск.
OpenAI по-прежнему используется для подготовки и проверки поста в общем бюджете $3.

Для следующей сводки замените urls (максимум 20) и digest_date через PR в develop.
Затем Actions → Test bot in private channel → main → collect_and_publish.
Поля urls содержат только HTTPS-ссылки на статьи из разрешённого списка издателей;
ссылки на Telegram, ChatGPT и служебные страницы не нужны.
Reuters сейчас не входит в разрешённый список и будет пропущен. Политические темы
также исключены редакционными правилами. Дата сводки не обновляет возраст статьи:
материал об ограничениях от 26 сентября может не пройти окно 48 часов.

Это импорт полной подборки, а не автоматическое чтение Gmail.
В проверенных письмах Gmail за 23–25 сентября были только обрезанные анонсы без
ссылок на первоисточники. Письма, адрес почты и приватные ссылки ChatGPT в репозиторий
не сохраняются. Автоматизация требует доставки полных ссылок отдельным способом.

Проверка фактов остаётся обязательной. Отказ проверки приводит к NO POST.
До успешной проверки в приватном канале develop не переносится в main.
